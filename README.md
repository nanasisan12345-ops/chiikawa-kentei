# ちいかわ検定

**公開URL：[ちいかわ検定](https://nanasisan12345-ops.github.io/chiikawa-kentei/)**

ちいかわの物語を楽しむ非公式ファン検定です。漫画・アニメ・映画本編のネタバレを含みます。開始前に注意文と確認チェックを表示します。

## 遊び方

- 5級・4級・3級・2級・1級・特級のどれからでも挑戦できます。各10問、時間制限なし。
- 合格ラインは5級・4級70点、3級・2級80点、1級90点、特級100点。1問10点です。特級の称号は「ちいかわ博士」。
- 各級に専用40問、合計240問を用意。毎回10問をランダムに出します。未出題を優先し、40問をひと巡りした後も直前10問は避けます。問題順と選択肢の並びも変わります。
- 出題履歴は級ごとに保存され、再読込後も継続します。旧版の4級・2級の途中回答と過去の記録も引き継げます。
- 回答を選んで「次の問題へ」。戻って変更でき、途中で閉じても同じブラウザで「続きから」再開できます。
- 採点後に全問の正解・解説・出典リンクを表示。不正解の解説は最初から開きます。
- 合格時は合格証を表示し、名前を入れて印刷できます。名前は保存しません。級と合格証は本サイト独自の記念です。
- 合格証はリボン風の飾りと淡い色でデザインし、級を中央に大きく表示します。
- 最近20回の記録をブラウザ内に保存します。級の「最近の最高」もその20回を対象にします。
- トップ画面・結果画面の下部にある、白と淡い緑の案内カードから[ちいかわキャラマッチ](https://nanasisan12345-ops.github.io/chiikawa-character-match/)へ移動できます。

## ローカル起動

Node.js 22以降とMicrosoft EdgeのあるWindowsで `run.bat` をダブルクリック。`http://127.0.0.1:4174/` で起動します。終了時はブラウザと起動ウィンドウを閉じます。

専用ブラウザの状態はプロジェクト内の `Data/browser/` に保存します。公開サイトや通常のブラウザでは、そのブラウザの保存先に従います。回答を外部サーバーへ送信する機能はありません。

保存キーは `chiikawa-kentei:v1`。キャラ診断とは分離しています。「保存した記録を消す」で、この検定の回答と記録だけを消せます。

## 開発

```sh
npm test
node tools/serve.mjs
node tools/browser-check.mjs
npm run build
```

実行時の外部依存なし。ブラウザ検証はPlaywrightとWindows Edgeを使用します。`PLAYWRIGHT_PATH` にPlaywrightの場所を指定できます。検証ブラウザも `Data/` に保存します。

`data.js` と `extra-questions.js` に問題と確認元、`engine.js` に出題・採点・保存、`script.js` に画面処理をまとめています。正答の位置は表示時にシャッフルします。採点には元の選択肢IDを使います。

## 公開

GitHub Actionsで `main` へのpush後にテスト、ビルド、GitHub Pages公開を行います。毎回新しい `.build/pages_日時/` を作り、サイト本体の8ファイルだけを公開します。Dataや検証画像、配布パッケージ、ZIPは公開しません。

## 出題について

人物紹介・単行本紹介・アニメ公式の話数一覧・制作インタビューなどから出題しています。草むしり検定、オデ、石、悪夢、セイレーン編、食べ物、キャスト・楽曲・制作の裏話を含みます。各問題の解説から参考ページを開けます。スタッフ情報は問題文の確認時点に基づきます。

特級には、ハチワレの声の変化を取り上げた報道と、「あのこはグレーの子だった」「モモンガとでかつよは中身が入れ替わっている」というファンの考察も含みます。声変わりの正確な時期や学年は断定しません。考察には開始前・問題・解説で「本当の情報だと公式に確認できていません」と表示し、非公式の参考記事へリンクします。考察問題の正解は、その説の内容に合う選択肢という意味です。
